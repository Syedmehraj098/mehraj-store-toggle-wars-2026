## A/B Testing Experiment

Experiment Name: MEHRAJ STORE - Shopping Layout A/B Test

Feature Flag: `shopping_layout_test`

### Control Variant (50%)

- Standard shopping experience
- Welcome to Mehraj Store
- Shop Now button

### Premium Variant (50%)

- Premium shopping experience
- Discover the Premium Collection
- Explore Now button

## Hypothesis

The premium shopping layout is expected to increase product exploration by at least 10% compared to the control layout within 14 days.

## Primary Metric

Product Exploration Rate

Tracking Event: `product_explored`

- Traffic rollout: 100%
